# 晚风骑行

根据一张珠江边的照片创作的纯 SVG 二维动画：女孩骑着自行车，大黄狗在身后跟跑，背景有广州塔和江景。

- 在线预览：[GitHub Pages](https://mastercatone.github.io/guangzhou-evening-ride/)
- 动画页面：[`ride.html`](ride.html)，直接用浏览器打开即可，无需安装依赖。
- 根目录的 `index.html` 会跳转到动画页面，供 GitHub Pages 使用。
- 播放测试：`node animation.test.cjs`（需要 Node.js）。

动画支持播放或暂停、三档速度、昼夜场景，并遵循系统的减少动态效果设置。
